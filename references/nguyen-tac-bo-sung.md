# Nguyên tắc bổ sung

Các nguyên tắc riêng do chủ repo thêm dần, dựa trên bài thật của học viên. Khi một nguyên tắc ở đây khác với danh mục mẫu chung, làm theo file này.

Cách thêm: mỗi nguyên tắc một mục, đánh số tiếp theo, ghi ngày thêm. Có ví dụ "Trước" và "Sau" càng tốt.

```
### BS-NN. Tên ngắn (thêm ngày dd/mm/yyyy)
**Quy tắc:** ...
**Trước:** ...
**Sau:** ...
```
